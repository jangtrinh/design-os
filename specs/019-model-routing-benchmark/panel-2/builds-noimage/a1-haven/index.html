What Haven refuses to do.

No fabricated benchmark, just the design decisions that shape every grant.

  • Scoped, not standing

    A grant is scoped to one secret, one purpose, and one expiry — never blanket vault access.

  • Short-lived by default

    New grants default to the shortest expiry that unblocks the request. Permanent access is the exception, not the setting.

  • Every read is attributable

    There is no anonymous or shared-account read. Every access maps to a named person or a named service.
