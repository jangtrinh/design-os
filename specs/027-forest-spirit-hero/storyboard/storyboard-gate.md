# Desktop Storyboard Gate

Status: `OWNER_APPROVAL_REQUIRED`

This 960×540 rough storyboard is the production gate for the desktop-only forest-spirit hero. It validates narrative staging and occlusion before final 1920×1080 assets or GSAP implementation are produced.

## Stations

1. `desktop/01-threshold.png` — enter the forest; shrine is only a dark suggestion.
2. `desktop/02-recognition.png` — spirit approaches; shrine remains unresolved.
3. `desktop/03-crossing.png` — spirit crosses toward the foreground obstruction.
4. `desktop/04-absence.png` — spirit disappears; visual tension peaks.
5. `desktop/05-reveal.png` — obstruction clears and the rooted shrine resolves.
6. `desktop/06-orbit.png` — spirit reappears and arcs around the shrine.
7. `desktop/07-settle.png` — spirit settles beside the shrine before page release.

## Locked Behaviors

- Desktop viewport only; mobile direction is deferred.
- The shrine never flies or drifts independently. Its slight movement comes only from scene perspective.
- Only the spirit follows a free flight path.
- Scroll advances one continuous cinematic camera move, then releases into the next section.
- Reduced motion uses `reduced-motion-settled-preview-1920x1080.png` as the settled state.

## Approval

Approval authorizes final asset generation and desktop GSAP implementation. Any requested staging change returns this gate to draft.
