# Paper-Technical Light Register

**Contract**
- Build primary surfaces on warm off-white paper tones, never stark white.
- Frame the light interior in a darker outer shell so content reads placed and intentional.
- Add quiet technical structure — thin borders, inset rules, small corner brackets, restrained fine diagonal texture on large fields.
- One crisp accent for active states and focal details while warm neutrals carry the interface.
- Keep outer shells softly rounded but inner layout logic crisp.
- Calm motion only.
- Tuning axes: paper warmth · framing strength · roundness · accent intensity · texture amount.

**Context**
Light-mode technical/product surfaces wanting warmth and tactility — memos, catalogues, documentation.

**Anti-context**
Dense data tables and statutory/spec surfaces (no texture, no warm-tint contrast loss, no bracket ornament there); urgent flows; any surface where texture threatens legibility.

---

This guidance is a contextual band, never a global default. Passing a deterministic check adds no taste credit.
