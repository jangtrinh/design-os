Self-serve conversion funnel, Q2

Eighty thousand pricing-page visits become eight thousand purchases. The steepest drop is the first one — nearly two thirds of visitors never start a trial.

Illustrative dataset — the four stage counts are invented to demonstrate the pyramid grammar and describe no real funnel. Encoding rule: width ∝ value, at 0.008 px per account measured from zero width; each tier's top edge encodes its own count and its bottom edge equals the next stage's count, so the taper is derived from the data rather than eyeballed. Tier heights are uniform — height is not a second encoded dimension — and the silhouette narrows monotonically. Every tier carries its name and its number as text, so the ordering and the magnitudes survive grayscale. Colour resolves through design-system tokens; where no project tokens are compiled the page falls back to the documented neutral palette declared in :root. Static, script-free, and offline.
